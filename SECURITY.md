# Segurança

## Como avisar uma vulnerabilidade

Use o aviso privado de vulnerabilidade do GitHub, no repositório
[NicolasKEYT/Klass](https://github.com/NicolasKEYT/Klass): aba **Security →
Report a vulnerability**. Só a equipe vê o aviso.

**Não abra issue pública** sobre falha de segurança.

Descreva o que encontrou, como reproduzir e o impacto que você imagina.

## Escopo

O Klass é um trabalho de conclusão de curso. A instância hospedada da equipe
é só de demonstração, com dados de teste; não teste ataques contra ela nem
contra contas de outras pessoas. Prefira reproduzir no banco local (ver
CONTRIBUTING.md).
